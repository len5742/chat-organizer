Chat Organizer 0.2.5 fixes compatibility with the updated desktop app.

- Read the current `sqlite/codex.db` ChatGPT metadata cache. Use the older `codex-dev.db` only when the current file is absent, and report current-cache errors explicitly.
- Defer newly discovered unnamed cloud execution records instead of adding internal IDs to Uncategorized or manufacturing chat titles from message text.
- Prefer explicit native names and retain saved titles when a source returns a message preview.
- Use saved names in exception reports when the captured label is an internal ID.
- Keep the previous panel resource available for already-open organizer panels.

Existing categories, flame marks, and chat assignments are preserved. This release does not automatically remove or remap previously imported cloud records.

For an existing public installation, replace its marketplace directory with the new plug-in archive, run `codex plugin add chat-organizer@chat-organizer-community`, and fully quit and reopen the desktop app. Retain the existing catalog and data-directory setting. Initial export import is only for a fresh catalog.

The source and packaged plug-in pass the Windows release checks. The public test suite includes current-cache selection, unreadable-cache reporting, deferred cloud discoveries, saved-title preservation, and exception naming.
